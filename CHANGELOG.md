# Changelog

All notable changes to the Adaptive Procedural Level Generation project will be documented in this file.

## [1.0.0] - 2026-08-18

### Initial Release
- **Core Engine & Architecture**: C++ core procedural generation engine (`Engine/`, `LevelEngine/`, `Generation/`, `Difficulty/`, `Validation/`, `Gameplay/`, `AI/`, `Physics/`, `Rendering/`, `Audio/`, `UI/`, `Utilities/`).
- **Godot 4 Integration**: GDScript bridge, node bindings, and Godot 4 demo project (`godot_project/`).
- **Standalone App**: Win32 / Direct2D standalone visualizer and test suite (`standalone/`).
- **Build Scripts & Configuration**: CMake build configuration (`CMakeLists.txt`), batch build script (`build.bat`), and bash script (`build.sh`).
- **Documentation**: Comprehensive architecture guide, system specifications (`README.md`), and Godot setup documentation (`GODOT_SETUP.md`).
